## Мини-выборка (data/bugs.csv)

Закрытые баги (`status=Closed`): HW-01, HW-02, HW-03, HW-04, HW-05, HW-06, HW-07, HW-08, HW-09, HW-10, HW-11, HW-12.

| Показатель                             | Строки в числителе доли                                           | Подстановка                                              | Результат |
|----------------------------------------|-------------------------------------------------------------------|----------------------------------------------------------|----------:|
| Локальный DCE                          | HW-01, HW-02, HW-03 - закрытые Critical/Blocker в prod            | 100 * (1 − crit_prod / closed_bugs) = 100 * (1 − 3 / 12) |   75,00 % |
| Доля закрытых багов, найденных до prod | HW-06, HW-07, HW-08, HW-09, HW-10, HW-11, HW-12 - найдены на test | 100 * closed_before_prod / closed_bugs = 100 * 7 / 12    |   58,33 % |

Проверка знаменателя: 3 критичных prod + 2 прочих prod (HW-04, HW-05) + 7 на test = 12 закрытых. HW-13, HW-14 и HW-15 исключены из обоих расчётов по статусу.

## Отдельный релиз (data/release.json)

| Метрика            | Формула и подстановка                                     |                Результат и единицы | Учебный ориентир |   Отклонение |
|--------------------|-----------------------------------------------------------|-----------------------------------:|-----------------:|-------------:|
| Локальный DCE      | 100 * (1 − crit_prod / closed_bugs) = 100 * (1 − 8 / 160) |                            95,00 % |          98,00 % |  −3,00 п. п. |
| Плотность дефектов | closed_bugs / requirements = 160 / 48                     | 3,333 закрытого бага на требование |                - |            - |
| Reopen rate        | 100 * reopened / closed_bugs = 100 * 24 / 160             |                            15,00 % |                - |            - |
| Coverage           | 100 * covered / requirements = 100 * 40 / 48              |                            83,33 % |          90,00 % |  −6,67 п. п. |
| Actuality          | 100 * actual / test_cases = 100 * 375 / 500               |                            75,00 % |          80,00 % |  −5,00 п. п. |
| Automation         | 100 * automated / test_cases = 100 * 240 / 500            |                            48,00 % |          75,00 % | −27,00 п. п. |

В reopen rate 24 - число уникальных закрытых багов, которые переоткрывали хотя бы раз.

При нулевом знаменателе результат обозначаем `N/A` и показываем исходные счётчики с пояснением. 
Например, если в потоке за период `closed_bugs = 0` и `crit_prod = 0`, DCE = 100 * (1 − 0 / 0) не определён. 
В отчёте указываем «DCE: N/A (0 закрытых багов за период)» и исключаем его из сравнения с ориентиром.
